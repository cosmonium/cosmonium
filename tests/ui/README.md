# User Interface Unit Tests

This directory contains unit tests covering functionalities related to the user interface of Cosmonium.

## Test Coverage

### 1. Loaders Tests (`loaders`)

This directory contains unit tests covering functionalities related to the loaders module of the user interface of Cosmonium.

- **loaders/test_parsers.py**: Unit tests for parser classes.
- **loaders/test_integration.py**:  Integration tests for UI configuration loaders.
