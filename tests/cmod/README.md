# Test Structure

- `test_cmod_parser.py` - Unit tests for CMOD parser
  - `TestCMODParserBinary` - Tests for binary CMOD format
  - `TestCMODParserASCII` - Tests for ASCII CMOD format
  - `TestCMODParserVertexFormats` - Tests for different vertex attribute formats
  - `TestCMODParserPrimitiveTypes` - Tests for all primitive types
  - `TestCMODParserEdgeCases` - Tests for edge cases and error handling
